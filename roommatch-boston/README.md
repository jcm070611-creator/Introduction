# RoomMatch Boston — Interactive prototype

This is a standalone Korean-themed RoomMatch Boston demo converted from the uploaded incomplete Gemini HTML style sample and the existing functional RoomMatch prototype.

Features: demo landing page, six fictional roommate profiles, compatibility scoring, preference controls, must-have filters, saved matches, comparison dialog, message draft.

No real student verification, actual housing information, transit estimates, login, backend, or message sending. The Gemini-exported HTML was truncated midway through CSS, so missing interaction code was reconstructed from the working RoomMatch prototype.
